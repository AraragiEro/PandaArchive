# 挖矿规定

## 基本要求

1. 使用大鱼作业的角色必须在 WC SeAT 登记 ESI。无法寻找到号主的大鱼角色必须抽取全部技能点，并重建新角色。本条没有例外，联盟所有成员必须遵守，联盟不定期抽查。1)
2. 符合以下条件的大鱼被抓将获得空船补损：用于挖矿的大鱼应当符合基本装配要求，有无敌技能与模块。在距离大鱼 130 km 处放置隐身诱导号。开始作业前加入值守语音频道。携带采掘者无人机的大鱼，且严格按照联盟红绿灯制度挖矿作业。正确开启无敌、正确呼救并及时退模块。
3. 对于未携带采掘者无人机的大鱼、未开工业模块的加成大鱼、采矿驳船或采掘者舰船，可不受红绿灯限制作业，但是没有补损。
4. 在场上有常规挖矿船被抓时，大鱼应当提早开启无敌，以保护常规挖矿船。
5. 违规的处罚措施包括：警告、关闭进站权限、罚款、击毙、踢出联盟群、列入黑名单。

## 异常空间

### 通用规则

1. 所有采矿舰船在气矿，冰带和主权矿业T2升级（包含格里米尔、克里石、尤加石、诺克希特、摩多石、凡晶石、赫佐利姆）的采矿作业行为受本规则限制。T1升级异常不在管控范围内。
2. 开始作业前，采矿舰船必须确认本星系矿带或者冰带情况。开采新的管控矿带前，需要优先清理未开采完毕的管控矿带（即使是仅剩下基辅断岩或零散小矿石的残矿带）
3. 禁止在开采管控矿带异常的过程中更换其他任何异常，当所有矿石均正在被开采的情况除外。
4. 禁止中途更换矿石；除非对方允许，否则禁止挖其它成员正在开采的矿石。
5. 两条大鲸鱼及以上的成员作业时必须自备小矿船清理体积较小的矿石或基腹断岩，碎矿全部开采完前小矿船不可离开。
6. 采矿驳船的矿枪不能分别开采不同矿石，蝗虫队作业时，每一矿石至少应该有三个或以上的驳船作业。蝗虫队作业时，如发现自己占用的矿石由于他人难以避免的失误，被其他驳船挖掘，请首先当场通过友好交流沟通解决问题。
7. 矿物异常作业完毕后请勿残留 货柜箱子、MTU或 Depot。如果挖完之后还有上述建筑可以击毁。

1. 蝗虫队作业时，如发现自己占用的矿石由于他人难以避免的失误，被其他驳船挖掘，请首先当场通过友好交流沟通解决问题。

### 矿带

1. 除了3级矿插以外，当矿点内有10个矿工开工后可以在报点频道内报点，报点后10分钟内任何人可以可以自由进入，10分钟后该异常锁定不允许新队伍进场。如果点内人数少于10人矿点会重新开放。
2. 3级矿插的矿点提升矿工人数至30人。
3. 任何船只在矿带仅余碎矿或基腹断岩，不适合大鱼开采的情况下，未清理完当前矿带即去其他矿带挖矿，将被顶格处罚。
4. 违规挖掘基辅断岩（无论任何原因）会立即进行处罚，包括不限于禁止入站、禁止使用市场服务、击毙等。
5. 严格禁止拆队伍同时占据多个矿点。
6. 挖矿远征的所有权对收到远征的玩家和他同意加入的玩家开放。

### 冰带

1. 同一星系挖冰船应集中在同一冰带，不允许同时开采多个冰带，除非上一个冰带的矿石都有矿船正在开采。
2. 只能从冰带两头开始挖掘，你所开采的矿石必须在整个冰带的最边缘。
3. 对于冰矿，你的投诉证据还需要有战术视角下，垂直由上向下截图。

### 气云异常

1. 主权区域内采气行为受本规则限制。
2. 后来者可以共同在同一气云异常内作业，但单个气云属于先挖的成员，离开自动失去气云所有权。
3. 不得开采其他人正在开采的气云。

## 月矿

1. 联盟拥有和管理月矿资源。
2. CN和EN的R32/R64各自分开管理. CN和EN的公开月矿管理规则也不同。
3. CN的月矿租赁规则在CN总监群公布信息，进入月矿协商群进行竞标/分配
4. 精炼和反应服务归联盟管理

## 其他

- 如果遇到违反规则的行为，请携带完整高清截图向公司总监报告。截图中应当包含当前星系、当前矿带、矿带剩余矿石、违规人员正在挖掘的矿石、当前矿带是否有其他成员等一切必要信息。
- 不同语言成员交流过程中出现纠纷时，可要求军团管理或联盟管理协助解决。
- 联盟会以公布的规则作为管理的依据，但保留最终解释权。
