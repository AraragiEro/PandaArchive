# Mumble 纪律

我们使用 Mumble 软件，并只接受它作为联盟语音系统。

具体配置教程详见Mumble。

[Mumble](https://wiki.winterco.org/zh/guide/it/mumble)

## 基本要求

1. 上游戏必须在某一个 Mumble 频道。你可以使用AFK全静音频道，或者自己的公司小频道。
2. 使用超期刷怪和大鱼挖矿必须能在语音频道说话。求救时必须在正确的战区值守频道，并能够清晰准确描述情况。
3. 战区值守频道一般情况下保持静默，不要在这里讨论和游戏无关的话题。
4. 不得打断FC说话。
5. 除特殊保密要求外，公司管理鼓励或带头使用其他语音的会受到严重警告和惩罚。
6. 如果你在影响频道秩序，值守FC有禁言和踢出成员的权限。 如果你认为FC滥用了这个权力可以找总监群投诉
