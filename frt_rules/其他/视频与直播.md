# 视频与直播

外部链接：联盟规则关于游戏内直播，视频制作

[联盟规则关于游戏内直播，视频制作](https://forums.winterco.org/t/topic/2148/1)

## 适用范围

联盟群的 PVP / PVE 舰队

## 视频制作

- 遮挡 联盟(Alliance)、舰队(Fleet) 频道，关注列表(Watch List)
- 必要时遮挡友军总览紫色 ID
- 不使用全程录音
- 如发布舰队视频，当事FC有权利要求不公开视频

## 直播

- 遮挡 联盟(Alliance)、舰队(Fleet) 频道，关注列表(Watch List)
- 必要时遮挡友军总览紫色 ID
- 不允许直播有联盟群频道 Mumble 语音 (包括舰队与值守频道)
- 直播延迟至少 10 分钟
